GUAITAcorpus
User manual

A document repository with a viewer, content search, relationship graph, and AI assistant — all in a single file

guaitaCorpus organizes a folder of PDF, HTML, Markdown, EPUB, LaTeX, and BibTeX documents: it keeps them in their original format, builds metadata records for them, indexes them for full-text search, draws their relationship graph, and, if you set it up, lets you ask questions about them with an external AI model. Everything happens in your browser and in your own folder — no server, no account, no installation.

01 · Getting started

Opening a document repository

guaitaCorpus doesn't import any document into an internal database: you choose a folder on your computer (the document repository) and it works directly on it, through the browser's file access API.

  1. Press Choose root folder in the header and select the folder where you keep or want to keep your documents.
  2. The browser will ask for read and write permission for that folder. You need to accept it so the app can save records, indexes, and imported documents.
  3. guaitaCorpus scans the folder (and its subfolders) for .pdf, .html, .htm, and .md files, and lists them on the left.
Next time you open the app in the same browser, it will try to reconnect automatically to the last folder. If the browser has revoked the permission, the Reconnect folder button appears.

HTML files that belong to the same Guaita Apps suite (detected by their license header, not by name) are automatically excluded from the list so they don't index themselves or each other.

02 · Getting started

The viewer

Click any document in the list to open it in the main panel:

PDF

Shown with the browser's native reader (the same one you'd use opening a PDF directly). No add-on needed.

HTML

Loaded in an isolated frame (sandbox) so its own code can't interfere with the app.

Markdown

Converted to HTML with a small built-in engine (headings, lists, quotes, code, bold, and italics) and shown on a clean reading sheet.

EPUB

Full reader with a table of contents and chapter navigation — see the next section.

LaTeX (.tex)

Shows the source code with light highlighting of commands, environments, and comments. It doesn't compile the file or generate a PDF from it.

BibTeX (.bib)

Instead of raw text, the entries are parsed and shown as a list with title, authorship, and year.

Checking for new documents in the folder is manual: press ⟳ Refresh after you've added or moved files from outside the app.

03 · Getting started

EPUB reader

When you open an EPUB, the main panel splits into two columns: the book's table of contents on the left and the current chapter on the right.

  • Click any entry in the table of contents (including sub-sections) to jump straight to it.
  • ← Previous and Next → move forward according to the reading order defined by the book itself.
  • Images and internal stylesheets of the chapter display correctly; no internet connection needed.

The table of contents is read from the EPUB itself (EPUB 3 or EPUB 2 format); if the book doesn't carry one, a simple list is generated from the order of the chapters.

04 · Getting started

Importing documents

The Import button opens a drawer with three ways to grow the document repository:

MethodWhat it does
URL or DOIIf you paste in a DOI, it queries CrossRef and shows title, authorship, and year to help you identify the article — it doesn't download the PDF itself (due to browser restrictions).
BookmarkletA link you drag to your bookmarks bar. From any web page, clicking it sends that content to guaitaCorpus.
Drag / choose filesDrop PDF, HTML, MD, EPUB, TeX, or BibTeX files on the indicated area, or choose them with the system picker. They're copied into the root folder.
The bookmarklet opens a window pointing at guaitaCorpus's current address. If you opened it as a local file (file://), many browsers block this kind of opening from an external page. It works reliably if you serve the app from a local server.

When the content is HTML (dragged in or captured by the bookmarklet), a dialog appears with two options:

  • Save original HTML: saves the HTML as-is into the folder, as a snapshot.
  • Print to PDF: opens the browser's print dialog so you can save it yourself as a PDF (the browser doesn't allow doing this fully automatically).

05 · Organize

Document metadata

With a document open, press Metadata to view and edit its metadata: title, authors, year, tags, whether you've read it or starred it, and quick notes.

  1. Fill in whichever fields you need. Tags are shown as colored chips — the color is generated by the app from the tag's text, always the same for the same word.
  2. Mark the collections you want the document to belong to (see below).
  3. Add manual relations to other documents in the repository, with a free-text label such as "cited by" or "version of".
  4. Press Save metadata.
Each record is saved as a small .guaita.json file next to the original document, with the same name plus this suffix. The document itself is never modified.

06 · Organize

Collections

Collections let you group documents without moving them. They're created with the + button on the collections bar (below the search box), and filtered by clicking their chip — "All" removes the filter.

For now collections are flat (no nested sub-collections).

07 · Organize

Duplicate detection

guaitaCorpus computes, in the background, a digital fingerprint (SHA-256) of each document. If two files have exactly the same content, both are marked in the list with the ⧉ badge; hover over it to see which other file it's a copy of.

Files larger than 25 MB are not compared, so as not to slow down the app.

08 · Organize

Notebook

The Notebook button brings all notes together in one place: the ones you've added from the metadata record of each document, and standalone notes that don't belong to any particular file.

  • Write [[some text]] inside a note to turn it into a link; clicking it filters the Notebook by that text.
  • Each document note shows which file it belongs to; click it to open that file.

09 · Find

Search and filters

The search box in the sidebar searches simultaneously through the file name, title, authors, tags, and the full content of the documents (PDF included, thanks to a built-in text extraction engine).

Unread / StarredFilter by the status marked in the record.
Recent (7d)Documents modified in the last 7 days.
PDF / HTML / MDFilter by file type.

Filters can be combined (they work as a conjunction: all of them must be satisfied at once). With the 💾 button you can save the current combination of search, filters, and collection as a saved search, which appears as a 🔖 chip under the search box — click to apply it again, double-click to delete it.

Text indexing runs in the background right after opening or refreshing the folder. While it's running (visible in the footer), content search may not yet find every document.

10 · Find

Relationship graph

The Graph button opens a full-screen visualization with all documents as nodes. Connections are drawn for three reasons:

ColorSource of the relation
GrayShared tag (only if shared by between 2 and 8 documents — tags that are too common aren't drawn, so as not to clutter the graph).
BlueBelonging to the same collection.
Dashed limeManual relation added from a document's record.

Drag nodes to rearrange them, drag the background to pan the view, scroll the mouse wheel to zoom, and click a node to open that document.

11 · Assisted

AI Assistant

The AI drawer connects guaitaCorpus to an external language model, entirely under your control:

  1. Choose the format (OpenAI-compatible or Anthropic), the endpoint, your API key, and the model name, then press Save configuration.
  2. Use Ask to ask questions about the corpus: guaitaCorpus selects the most relevant documents according to the search index, sends fragments of them as context, and the answer cites which documents it used.
  3. Summarize generates a summary of the open document; you can save it as a note with one click.
  4. Suggest proposes tags based on the content. They're shown as chips: no tag is added until you click one individually.
The configuration (including the API key) is saved only in the browser (localStorage), never inside the document repository folder. Don't share it if you sync or version-control this folder.
Depending on the provider, calling it directly from the browser may run into CORS restrictions. If it fails, the error shows the HTTP code returned by the server.

12 · Assisted

Bibliography and citation

The Bibliography drawer always works on the documents currently visible in the list (it respects the search box, filters, and active collection).

  • Export — generates a .bib (BibTeX), .ris, or .json (CSL-JSON) file in the root folder, based on the metadata records.
  • Formatted citation — choose a style (APA, Chicago author-date, IEEE, or MLA) and press Generate bibliography to get it already formatted. You can also load any other custom .csl style.
  • Import BibTeX / RIS — drag or choose a file; each entry is matched by title similarity to a document already present in the repository (it never creates new ones). Review the marked matches before pressing Import checked items.

ISO 690 has no official CSL implementation available, which is why it isn't included by default among the built-in styles — load a custom one if you need it.

13 · Assisted

Read aloud

With a document open, the viewer's top bar offers 🔊 Read aloud, ⏸ Pause, and ⏹ Stop, using the browser's own speech synthesis (no external service). It reads the text already extracted from the document, in English.

If the text hasn't finished being extracted yet (indexing in progress), it will let you know — try again in a few seconds.

15 · Reference

Frequently asked questions
The browser doesn't offer me "Choose root folder"

You need a browser with support for the File System Access API (recent Chrome or Edge). Other browsers don't implement it yet.

I reopened the app and it's asking me to reconnect

That's normal: for security, the browser doesn't keep write permission indefinitely without confirmation. Press Reconnect folder.

The bookmarklet does nothing when I click it

This usually happens when guaitaCorpus was opened directly as a file (file://). Serve the app from a local server so the bookmarklet can open a window from it.

Search doesn't find text inside a PDF I know is there

Check the indexing indicator in the footer — it might still be processing the larger documents. If the PDF is a scanned image with no text layer, it can't be indexed (guaitaCorpus doesn't do OCR).

My tags or notes have disappeared

Check that the root folder is the same one as before: metadata lives in .guaita.json files inside the folder, not inside the browser.

Is it safe to paste in my API key?

It's saved only in this browser's localStorage, never in the folder or on any guaitaCorpus server. Even so, treat it with the same care as any password.
